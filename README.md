# NammaSanthe Ledger 📊

A modern, efficient, and easy-to-use Udari (Credit/Debit) management application for small business owners and shopkeepers. Built with Jetpack Compose and Material 3.

## 🚀 Features

- **Customer Management**: Add and track customers with ease.
- **Udari Tracking**: Record credits (Udari) and payments instantly.
- **Real-time Balance**: View total outstanding and individual customer balances on the home dashboard.
- **WhatsApp Integration**: Send professional payment reminders directly via WhatsApp.
- **Transaction History**: Detailed timeline for every customer.
- **Modern UI**: Clean, responsive design following Material 3 guidelines.
- **Offline First**: All data is stored securely on your device using Room Database.

## 🛠 Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Database**: Room Persistence Library
- **Architecture**: MVVM (Model-View-ViewModel)
- **Dependency Management**: Gradle Version Catalog / BOM
- **Navigation**: Jetpack Compose Navigation
- **Asynchronous Work**: Kotlin Coroutines & Flow

## 🏗 Setup & Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/NammaSantheLedger.git
   ```
2. Open the project in **Android Studio (Ladybug or newer)**.
3. Wait for Gradle sync to complete.
4. Run the app on an emulator or physical device.

## 📦 Building the APK

To generate a debug APK, run:
```bash
./gradlew assembleDebug
```
The APK will be available at `app/build/outputs/apk/debug/app-debug.apk`.
